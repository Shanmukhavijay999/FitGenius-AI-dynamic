# Database Configuration & Migrations

This directory contains the SQLAlchemy database models, Supabase integration scripts, and Alembic migrations.

## Tech Stack
- **Database**: PostgreSQL (via Supabase)
- **ORM**: SQLAlchemy
- **Migrations**: Alembic

## Layout
- `models/`: Database schema models (Users, Products, SizeCharts, Customers, Recommendations, Analytics).
- `migrations/`: Alembic migrations folder.
- `alembic.ini`: Alembic configurations.
